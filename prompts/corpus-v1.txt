Edge inference places language models close to the person using them. A reproducible experiment records the model checkpoint, quantization, runtime, device, prompt, and generation settings. Prompt processing computes the initial context; decoding then generates tokens one at a time. Memory includes weights, key and value caches, work buffers, and runtime overhead. The amount of memory occupied by a request differs from the configured context capacity. Wall time includes work that a kernel benchmark may omit, including tokenization and sampling. A fair comparison separates prompt processing from decoding, keeps individual measurements, and reports uncertainty. Power measurements need an explicit boundary because battery charging and other device activity can contribute to input power. Thermal conditions and background activity can alter observed speed. A failure is evidence about the tested configuration and conditions, not proof that every related model will fail. Controlled synthetic work can isolate token budgets; semantic quality requires a separate task and evaluation. Describe the measurement method, retain original logs, and avoid extending conclusions beyond observed devices and workloads.
